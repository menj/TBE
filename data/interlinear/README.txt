Interlinear data
================
Hebrew Old Testament, word by word: the Westminster Leningrad Codex with transliteration,
English gloss, Strong's number, root word and grammar.

Source: STEPBible-Data (https://github.com/STEPBible/STEPBible-Data), file set TAHOT
(Translators Amalgamated Hebrew OT). Data created by STEPBible.org based on work at
Tyndale House Cambridge. Licensed CC BY 4.0: https://creativecommons.org/licenses/by/4.0/

This folder holds a reformatted copy of that data (one compact JSON file per chapter),
produced by tools/build_interlinear.py. The data itself is unchanged. Please refer to
https://github.com/STEPBible/STEPBible-Data as the original source.
